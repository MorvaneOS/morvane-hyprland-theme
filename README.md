# morvane-hyprland-theme

The MorvaneOS look for Hyprland: a Pastel Pink to Lavender border on the focused
window (unfocused windows get a dim one, so focus isn't shown by hue alone), and the
Twilight wallpaper instead of Hyprland's own.

Hyprland reads only `~/.config/hypr/hyprland.lua`. New users get one that runs
Hyprland's example config and then this theme:

```lua
dofile("/usr/share/hypr/hyprland.lua")
dofile("/usr/share/morvane-hyprland-theme/theme.lua")
```

so both follow package updates, there's no "autogenerated config" warning, and you
can add your own settings below (later settings override earlier ones). Existing
users keep their own config; add the second line to it for the MorvaneOS look.

Terminal (kitty), notification (dunst) and launcher (wofi) colours come from
[morvane-wm-theme](https://github.com/MorvaneOS/morvane-wm-theme), apps from
[morvane-gtk-theme](https://github.com/MorvaneOS/morvane-gtk-theme). The MorvaneOS
installer installs this package with Hyprland.

## Changing it

Edit `tools/build.py`, then:

```
python tools/build.py
```

Needs only Python. Commit the output, bump `pkgver`, build and publish.
